# new_solve
Repository per testare una nuova versione di SOLVe

## Contenuto

- `vocabolario/` – thesaurus SKOS dei temi (macrotemi e sottotemi) agganciato ai vocabolari standard SeaDataNet/EMODnet e INSPIRE. Vedi `vocabolario/README.md`.
- `scripts/` – script di generazione e raccolta dati.

## Prossimi passi

1. Revisione del vocabolario.
2. Raccolta del catalogo pubblico di SOLVe e classificazione dei layer sui temi.
3. Integrazione dei dati Venezia2021.
4. Sito statico con il grafo dei temi e le liste dei layer.
